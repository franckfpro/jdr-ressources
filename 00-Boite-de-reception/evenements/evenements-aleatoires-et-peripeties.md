# Événements Aléatoires et Péripéties

| Jet (d100) | Description de l'événement |
|:---:|---|
| 01-05 | **Attaque ou Embuscade** : Un ennemi ou une menace vous prend par surprise. |
| 06-10 | **Rencontre fortuite** : Un PNJ (voyageur, marchand, fuyard) croise votre route. |
| 11-15 | **Découverte marquante** : Un lieu étrange, caché, sacré ou ancien se révèle à vous. |
| 16-20 | **Obstacle environnemental** : Un éboulement, une inondation ou un pont brisé bloque la voie. |
| 21-25 | **Indice ou Piste** : Vous trouvez un élément inattendu lié à votre quête actuelle. |
| 26-30 | **Caprice de la météo** : Un changement brusque et dangereux du climat s'abat sur vous. |
| 31-35 | **Problème matériel** : Un équipement essentiel se brise, est perdu ou volé. |
| 36-40 | **Bête sauvage** : Une créature ou une bête monstrueuse croise votre chemin. |
| 41-45 | **Trouvaille de valeur** : Vous découvrez un butin mineur, des ressources ou un objet curieux. |
| 46-50 | **Phénomène étrange** : Un événement magique, surnaturel ou inexpliqué se produit. |
| 51-55 | **Danger pour un tiers** : Un allié, un compagnon ou un innocent se retrouve en grand péril. |
| 56-60 | **Nouvelle ou Rumeur** : Vous apprenez une information alarmante ou inattendue. |
| 61-65 | **Piège ou Embûche** : Un mécanisme caché ou une embûche naturelle se déclenche. |
| 66-70 | **Conflit de faction** : Vous tombez sur une dispute ou un affrontement entre deux groupes. |
| 71-75 | **Épuisement des ressources** : Vous manquez soudainement d'eau, de nourriture ou de soins. |
| 76-80 | **Désorientation** : Vous perdez votre chemin ou êtes forcé de faire un grand détour. |
| 81-85 | **Opportunité morale** : Quelqu'un a désespérément besoin d'aide, mais cela vous retardera. |
| 86-90 | **Manifestation du passé** : Un élément lié à votre historique ou à un ancien ennemi refait surface. |
| 91-95 | **Vision ou pressentiment** : Vous subissez un rêve prophétique, un malaise ou une étrange réminiscence. |
| 96-00 | **Rebondissement majeur** : La situation dérape complètement, modifiant l'objectif de la scène. |
