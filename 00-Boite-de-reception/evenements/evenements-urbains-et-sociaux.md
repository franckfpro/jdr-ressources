# Fiche d'Événements Urbains et Sociaux (d100)

| Jet | Catégorie | Description détaillée de l'événement |
|---|---|---|
| 01-05 | Rumeur toxique | Un crieur public ou un réseau de communication diffuse une nouvelle alarmante. Les forces de l'ordre bouclent immédiatement le secteur. |
| 06-10 | Larcin discret | Un voleur professionnel tente sa chance. Si le personnage manque de vigilance, un objet important disparaît de son inventaire. |
| 11-15 | Conflit ouvert | Deux factions rivales s'affrontent violemment en pleine rue. Le personnage est pris entre deux feux et doit fuir ou choisir un camp. |
| 16-20 | Marché noir | Un individu propose discrètement un objet d'une technologie ou magie rare à un prix dérisoire. L'objet est évidemment volé ou traqué. |
| 21-25 | Quiproquo | Un avis de recherche très rémunérateur est affiché publiquement. Le portrait craché de la cible est le personnage lui-même. |
| 26-30 | Contrôle d'autorité | Des gardes ou officiers exigent une identification stricte et une taxe de passage. Refuser ou fuir lance une alerte générale. |
| 31-35 | Célébration | Une fête locale envahit les rues. C'est idéal pour échapper à des poursuivants, mais terrible pour se déplacer rapidement d'un point A à un point B. |
| 36-40 | Remise forcée | Un inconnu bouscule le personnage en fuyant et lui glisse un paquet scellé dans les mains avant de disparaître dans la foule. |
| 41-45 | Extorsion | Dans une ruelle ou un couloir désert, un groupe mal famé exige un péage immédiat pour garantir la sécurité du passage. |
| 46-50 | Visage familier | Une ancienne connaissance, alliée ou ennemie, est aperçue à la table d'un bar local ou lors d'une transaction commerciale. |
| 51-55 | Incident mystérieux | Un incident grave (explosion mineure, personne tombant d'un toit) se produit juste aux pieds du personnage. Tous les témoins le regardent. |
| 56-60 | Contrat officieux | Une figure bourgeoise aborde le personnage avec une offre d'emploi très lucrative nécessitant une totale discrétion et moralité discutable. |
| 61-65 | Désastre civil | Un véhicule s'emballe ou une structure menace de s'effondrer sur des passants. Intervenir est héroïque mais retarde les objectifs personnels. |
| 66-70 | Scandale public | Une personnalité influente est attaquée ou humiliée en public. Prendre sa défense garantit un appui politique futur de grand poids. |
| 71-75 | Surveillance active | Le personnage a la certitude tenace d'être suivi. Son poursuivant est remarquablement doué pour se fondre dans la masse. |
| 76-80 | Aubaine suspecte | Un conteneur précieux est trouvé abandonné sur un banc ou un comptoir. Il est déverrouillé, mais son propriétaire fouille activement la zone. |
| 81-85 | Incendie/Alerte | Une alerte majeure retentit (feu, fuite toxique, attaque). La foule paniquée bloque toutes les issues principales. |
| 86-90 | Erreur de livraison | Un messager confond l'identité du personnage et lui remet des documents ou données hautement confidentiels concernant une faction locale. |
| 91-95 | Zélateurs | Un groupe de fanatiques encercle le personnage, exigeant une conversion immédiate, un don financier ou un test d'allégeance idéologique. |
| 96-100 | Rencontre providentielle | Une figure d'autorité bienveillante ou un contact providentiel offre son aide, effaçant une dette ou soignant une blessure gratuitement. |
